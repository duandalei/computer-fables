计算机寓言

Computer Fables

十四则寓言，分作四类，每类按由浅入深的次序排列。
故事在前，谜底在后；想弄懂互联网，从第一类读起。

第一章

互联网基础

Internet

从把数据切碎开始，经地址与路由、可靠传输、名字解析，最后看一次请求的全程。

寓言 概念
碎成一百片的信 —— 一个关于“把信裁碎”的故事 分组交换 门牌与指路簿 —— 一个关于“东西在哪儿、路怎么走”的故事 IP 地址与路由 一封挂号信 —— 一个关于“丢了怎么办”的故事 TCP/IP 按名索址 —— 一个关于“记得名字，不记得门牌”的故事 DNS 回车之后 —— 一个关于“一次点击要经过多少手”的故事 一次请求的全程
第二章

Web 与应用

Web & Applications

HTTP 怎么说，TLS 怎么封，REST 怎么组织资源，JWT 怎么带身份，DOM 怎么把页面立起来。

寓言 概念
明码点菜 —— 一个关于“菜条人人都看得见”的故事 HTTP 封匣 —— 一个关于“让不该看的人看不见”的故事 TLS 认格不认人 —— 一个关于“生客也能取对货”的故事 REST 端点 一纸关引 —— 一个关于“不查名册也敢放行”的故事 JWT 一树千丁 —— 一个关于“把一族人放进一棵树”的故事 DOM
第三章

系统与运行

Systems

程序怎样在一个进程里分出许多线程，又怎样被装进一只箱子搬走。

寓言 概念
分场同灶 —— 一个关于“什么该分、什么该共”的故事 进程与线程 随班戏楼 —— 一个关于“换个地方就演不了”的故事 Docker 与容器化
第四章

机器学习

Machine Learning

模型怎样学得太好反而坏事，又怎样在一条街上分配注意力。

寓言 概念
记住每一场雨的人 —— 一个关于“懂得太多”的故事 过拟合 按牌分银 —— 一个关于“一条街上，谁该听谁”的故事 注意力机制
