# 计算机寓言 · Computer Fables

用中国旧行当的故事，讲计算机里的一些简单概念。每一则先讲故事，再揭谜底，最后附上与技术概念的逐条对照。

**在线阅读：<https://duandalei.github.io/computer-fables/>**

想弄懂互联网，建议按这个次序读：分组交换 → IP 地址与路由 → TCP/IP → DNS → 一次请求的全程。
